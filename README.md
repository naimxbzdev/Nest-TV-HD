## 📌 প্রজেক্ট পরিচিতি (Project Overview)

**Nest TV HD** (ব্র্যান্ডেড *by Naim Xbz*) হলো বাংলাদেশ-কেন্দ্রিক আধুনিক ওয়েব এবং স্মার্ট টিভি আইপিটিভি স্ট্রিমিং অ্যাপ্লিকেশন। এই প্ল্যাটফর্মে কোনো অতিরিক্ত অ্যাপ বা সেট-টপ বক্স ছাড়াই সরাসরি ওয়েব ব্রাউজারে ৩০০টিরও বেশি দেশি-বিদেশি লাইভ টিভি চ্যানেল আল্ট্রা এইচডি/৪কে কোয়ালিটিতে দেখা যায়।

এতে রয়েছে স্বয়ংক্রিয় **bKash** ও **Nagad** পেমেন্ট ভেরিফিকেশন সিস্টেম, অ্যাডমিন সাবস্ক্রিপশন ম্যানেজমেন্ট ড্যাশবোর্ড, এবং গ্রাহকদের নিজস্ব প্রাইভেট পেমেন্ট হিস্ট্রি ট্র্যাকিং।

## ✨ মূল ফিচারসমূহ (Core Features)

### 1. 🖥️ স্মার্ট টিভি সিনেমা ভিউ (Smart TV Cinema View)
- ব্রাউজারের ভেতরেই বাস্তবসম্মত **OLED 4K Smart TV** ডিসপ্লে সিমুলেশন।
- সাইবারপাঙ্ক অ্যাম্বিয়েন্ট ব্যাকলাইট (Ambilight Glow) এবং ইন্টিগ্রেটেড ডলবি অ্যাটমস ৭.১.২ অ্যাকোস্টিক সাউন্ডবার।
- টিভির রিমোট ছাড়াই সরাসরি অন-স্ক্রিন ট্যাব দিয়ে লাইভ প্রিভিউ চ্যানেল সুইচিং।

### 2. ⚡ ইন্টারেক্টিভ লাইভ ওয়েব প্লেয়ার (Live Web Player)
- **Hls.js** ইঞ্জিন চালিত বাফারলেস আল্ট্রা লো-ল্যাটেন্সি স্ট্রিমিং।
- অ্যাসপেক্ট রেশিও অ্যাডজাস্টমেন্ট, ফুলস্ক্রিন, লাইভ বিটরেট ইন্ডিকেটর (1080p 60FPS / 4K UHD)।
- অ্যান্টি-ফ্রিজ ও স্বয়ংক্রিয় রিকানেকশন প্রযুক্তি।

### 3. 🌐 ৩০০+ লাইভ চ্যানেল ডিরেক্টরি (300+ Channels Catalog)
- ক্যাটাগরি ফিল্টারিং:
  - 🇧🇩 **Bangla TV:** সময় টিভি, চ্যানেল আই, দীপ্ত টিভি, যমুনা টিভি, ৭১ টিভি, জিটিভি ইত্যাদি।
  - ⚽ **Live Sports:** টি স্পোর্টস এইচডি, স্টার স্পোর্টস ১-৩, সনি টেন, উইলো ক্রিকেট।
  - 🎬 **Indian Bangla & Movies:** স্টার জলসা, জি বাংলা, কালার্স বাংলা, স্টার গোল্ড, সনি ম্যাক্স।
  - 🧒 **Kids, News, Music & Infotainment:** কার্টুন নেটওয়ার্ক, ডিসকভারি, ন্যাশনাল জিওগ্রাফিক, এমটিভি।
- লাইভ সার্চ ও রিয়েলটাইম চ্যানেল ট্র্যাকিং।

### 4. 💳 বিকাশ ও নগদ পেমেন্ট গেটওয়ে (MFS Checkout System)
- অফিসিয়াল পার্সোনাল সেন্ড মানি নম্বর: **`01703223141`** (bKash & Nagad)।

## 🚀 ইনস্টলেশন ও রান করার নিয়ম (Installation Guide)

### ১. রিপোজিটরি ক্লোন করুন
```bash
git clone https://github.com/naimxbzbd/nest-tv-hd.git
cd nest-tv-hd
```

### ২. ডিপেন্ডেন্সি ইনস্টল করুন
```bash
npm install
```

### ৩. লোকাল ডেভেলপমেন্ট সার্ভার চালু করুন
```bash
npm run dev
```
ব্রাউজারে ওপেন করুন: `http://localhost:3000`

### ৪. প্রোডাকশন বিল্ড তৈরি করুন
```bash
npm run build
```

### ৫. টাইপস্ক্রিপ্ট ও লিন্ট চেক
```bash
npm run lint
```
